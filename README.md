# 健康管理 health-management

一个**纯前端、无后端**的健康管理应用：记录每日饮食 / 运动 / 睡眠，自动换算热量与营养素，给出健康建议，并支持**规划后续训练计划与打卡**。
数据只保存在本机（浏览器 localStorage 或桌面端本地存储），不上传任何服务器。

同时提供三种形态：**网页 / 安卓 App / Windows 桌面应用**。

---

## 功能一览

### 今日看板
- 健康综合评分（饮食贴合度 35% + 运动 25% + 睡眠 25% + 饮水 15%）
- 摄入 / 运动 / 净热量 / 睡眠时长，均显示「已完成 / 目标」
- 目标完成度：热量环、睡眠环、蛋白质 / 碳水 / 脂肪「x / 目标」
- 饮水追踪（固定槽位水滴 + 快捷加减 + 自定义毫升）
- 体重记录与近 7 天趋势
- 近 7 天趋势图（热量折线 + 睡眠：时长折线 / 质量柱状）
- 内置建议引擎 + **AI 个性化建议**

### 饮食
- 早 / 午 / 晚 / 加餐四餐记录
- 内置 75+ 种食物（可增删改、自定义分类）
- 支持**拼音 / 首字母搜索**（如 `jidan`、`jd` 都能搜到鸡蛋）
- **拍照识别食物热量**（调用视觉大模型，识别结果可手动改克数，营养按比例更新；可「存库」复用）
- 全天摄入汇总（热量 / 蛋白 / 碳水 / 脂肪）

### 运动
- 内置 18 种运动（可增删改）
- 走路 / 快走 / 跑步 / 爬楼 / 爬山等支持**速度 + 坡度**（ACSM 方程估算消耗）
- 走路支持**按步数**计算热量（步幅 ≈ 身高 × 0.415）
- 其余运动按 MET × 体重 × 时长 × 强度系数计算

### 睡眠
- 入睡 / 起床时间（自动处理跨午夜）、午睡、睡眠质量 1~5 星
- 睡眠质量以柱状形式体现在近 7 天趋势图中

### 训练计划（规划 + 打卡）
- 按周一~周日编排每周训练计划（动作来自运动库、计划时长、备注）
- **今日打卡**卡：显示「已完成 X / Y 分钟」、进度条、还差几项、剩余分钟
- 完成判定按**累计分钟**：已记录分钟 ≥ 计划分钟才算完成；**同类型多段按顺序分配**，不会互相顶账
- 「打卡」按钮只出现在所选日期那一行，且只补**还差的那部分分钟**，不重复记录
- 全部完成后显示「✓ 完成」（过去/今天保留；未来日期不显示任何标记）
- 删除可撤销

### 我的
- 身体资料（性别 / 年龄 / 身高 / 体重 / 活动水平 / 健身目标）
- 自动分析：BMI（中国成人分级）、体脂率、理想体重区间、BMR、TDEE、饮水目标
- 每日目标自动推荐（可改、可一键重算）：热量、蛋白质、碳水、脂肪、睡眠
- 数据导出 / 导入 JSON（含全部日志、食物库、运动库、训练计划）
- 外观：浅色 / 深色（首次跟随系统）
- AI 拍照识别设置（接口地址 / Key / 模型 + 一键测试连接）

## 技术栈

React 18 + TypeScript + Vite 5 + Tailwind CSS 3 + Zustand（persist）+ Recharts + date-fns + zod
桌面端 Electron 32；移动端 Capacitor 6（Android）。

## 快速开始

```bash
npm install
npm run dev        # 开发（http://localhost:5173）
npm run typecheck  # 类型检查
npm run build      # 构建到 dist/
npm run preview    # 预览构建产物
```

### 打包桌面应用（Windows）
```bash
npm run dist:win   # 产出安装版 + 便携版 exe
```

### 打包安卓 APK
需要 Android SDK（命令行工具即可）+ JDK 21，然后：
```bash
npm run build
npx cap sync android
cd android && ./gradlew assembleRelease
```
产物可用 `zipalign` + `apksigner` 签名。注意：本机安装依赖时建议
`ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm install` 可跳过 Electron 二进制下载。

## 目录结构

```
src/
  components/   UI 组件（弹窗、统计卡、图表、饮水/体重追踪等）
  pages/        今日 / 饮食 / 运动 / 睡眠 / 计划 / 我的
  store/        Zustand 状态（persist，含版本迁移）
  utils/
    calc.ts     核心算法（BMR/TDEE/目标、BMI、体脂、MET、ACSM、步数、睡眠、汇总、计划完成判定）

    foodVision.ts  拍照识别（OpenAI 兼容视觉接口）
    aiAdvice.ts    AI 个性化建议
    search.ts      拼音搜索
electron/     桌面端主进程（内置本地静态服务 + 安全加固）
android/     Capacitor 安卓工程
scripts/     自检脚本（selftest.ts 核心算法测试、smoke.cjs UI 冒烟测试）
```

## 数据与安全

- 所有数据保存在本机，导出为 JSON 才外带；**API Key 不导出**
- 导入 JSON 经过 zod 严格校验，并限制 5MB 以内
- 网页端启用 CSP（禁内联/远程脚本）；桌面端 Electron 开启 `sandbox`、关闭 Node 集成
- 桌面端拦截外部导航与新窗口、默认拒绝所有权限申请、生产环境禁用开发者工具
- 拍照上传前会先把图片压缩（长边 1024、JPEG 0.85），减少传输与token消耗
- **注意**：localStorage 里的数据会随浏览器清理而丢失，跨设备迁移请用导出 / 导入 JSON

## AI 功能怎么用

在「我的 → AI 拍照识别设置」里填写**接口地址 / API Key / 视觉模型**并开启，
拍照识别和 AI 建议会复用同一套配置（视觉模型同样能处理纯文本对话）。

- 点预设标签可一键填入地址与模型（如硅基流动 `Qwen/Qwen3-VL-8B-Instruct`）
- 点「测试连接」会校验地址连通性，并**核对模型名是否在服务列表里**
- 常见报错：模型名不存在（平台迭代快，需以控制台/定价页为准）；`Failed to fetch`（跨域或地址问题）
